# WNBA Interactive Analytics Dashboard 

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ayrhoden3/VSCODE-Projects/blob/main/Colab_Project/Wnba_Assignment.ipynb)

## Overview
This repository contains a capstone project developed for the **AI in Sports** course run in partnership with **Stats Perform**. The notebook provides an interactive data analysis and visualization tool that extracts actionable insights from Women's National Basketball Association (WNBA) performance datasets. 

By leveraging Python's data science stack and interactive widgets, this project translates raw basketball statistics into a dynamic dashboard for real-time statistical exploration and tactical analysis.

## Tech Stack
* **Language:** Python
* **Data Processing & I/O:** Pandas, NumPy, OS, Zipfile
* **Interactive UI:** IPyWidgets, IPython
* **Data Visualization:** Plotly Express, Matplotlib

## Key Features
* **Interactive Data Exploration:** Utilizes `ipywidgets` to allow users to dynamically filter and select specific WNBA teams, players, or metrics without needing to alter the core code.
* **Advanced Visualizations:** Leverages Plotly Express and Matplotlib to generate highly customizable charts, tracking performance trends and comparative player analytics.
* **Automated Data Pipeline:** Programmatically extracts, cleans, and processes raw zipped data files into structured Pandas DataFrames for immediate analysis.
